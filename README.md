# tabsheet — 타브 악보 영상 → 악보 PDF/JPG (브라우저 버전)

영상에서 **악보가 나오는 사각형 영역**만 잘라, 악보가 바뀔 때마다 한 조각씩 모아 PDF 또는 JPG로 만듭니다.
서버도 설치도 없는 정적 웹페이지(`docs/`)이며, 영상은 업로드되지 않고 **브라우저 안에서만** 처리됩니다.
이미 내려받은 영상 파일을 불러오는 방식입니다 (유튜브 URL 입력은 지원하지 않음).

> 이전의 파이썬 버전(CLI + 로컬 서버 GUI)은 브랜치 `python-legacy`에 보존되어 있습니다.

## 실행

```bash
python -m http.server 8000     # 프로젝트 루트에서 실행 → http://127.0.0.1:8000/docs/
```

`docs/` 폴더만 정적 호스팅(GitHub Pages 등)해도 됩니다. 이 경우 서버의 `videos/` 목록은 나타나지 않습니다.

## 사용법

1. **영상 열기**: 파일을 끌어다 놓거나 선택. 프로젝트 루트에 `videos/` 폴더가 있으면 옵션 없이 자동으로 목록이 나타납니다(테스트용, 없으면 아무것도 표시하지 않음). **내 컴퓨터 폴더 선택**으로 폴더 안의 영상을 고를 수도 있습니다.
2. **악보 영역**: 영상을 열면 악보로 보이는 영역(밝은 띠 + 악보선)을 자동으로 잡아 줍니다. 못 찾았거나 맞지 않으면 악보가 보이는 시점으로 슬라이더를 옮기고, 화면에서 드래그하거나 x/y/너비/높이를 직접 입력해 미세 조정. 선택 상자의 점(모서리·변)을 끌면 크기만 바뀌고, **가로 전체** 버튼은 높이는 두고 영상 폭 전체로 넓힙니다.
3. **악보 추출**: 필요하면 시작/끝 시간(`90`, `1:30`, `1:02:03` 형식)과 세부 설정(항목 옆 `?`에 마우스를 올리면 값이 높을 때/낮을 때의 차이가 보입니다)을 바꾼 뒤 추출 → 조각 미리보기에서 필요 없는 조각 체크 해제 → PDF/JPG 만들기.

추출이 끝나면 걸린 시간이 표시됩니다. PDF/JPG 만들기 버튼은 결과 목록 맨 위(모두 선택/해제 옆)에 있어 스크롤해도 따라옵니다. 처리 중에는 이 탭을 닫지 마세요 (다른 탭으로 옮겨도 계속 진행됩니다). 추출하는 동안에는 화면이 꺼지지 않게 해 둡니다(지원 브라우저).

### 설치·오프라인

https 주소(또는 localhost)로 열면 브라우저의 "앱 설치"/"홈 화면에 추가"로 설치할 수 있고, 한 번 연 뒤에는 인터넷 없이도 동작합니다. 온라인일 때는 항상 서버의 최신 파일을 쓰므로 업데이트가 늦게 반영되지 않습니다. `docs/`에 js 파일을 추가하면 `sw.js`의 `SHELL` 목록에도 넣어야 합니다(테스트가 확인).

### 휴대폰·태블릿

같은 주소에서 손가락 입력 기기(`pointer: coarse`)로 인식되면 화면이 이렇게 바뀝니다. PC 화면은 그대로입니다.

- 맨 위에 "PC에서 훨씬 빠르게 처리됩니다" 안내 (× 로 닫으면 다시 안 뜸)
- 선택 상자 점이 커지고 손가락 판정 범위가 넓음, 폴더 선택 버튼 숨김
- 물음표는 탭하면 열리고 다시 탭하면 닫힘
- PDF/JPG는 공유 시트로 넘겨 "파일에 저장"·"사진에 저장" 등을 고름 (JPG는 여러 장을 한 번에). 만드는 데 오래 걸려 바로 안 뜨면 **저장·공유하기** 버튼이 나타남
- 다른 앱으로 넘어가면 추출이 멈췄다가 돌아오면 이어서 진행 (휴대폰 브라우저는 화면 밖 페이지를 멈추므로 막을 수 없음)

휴대폰은 영상 디코딩이 느려 PC보다 몇 배 오래 걸릴 수 있고, 긴 1080p 영상은 메모리 부족으로 탭이 새로고침될 수 있습니다. 시작/끝 시간으로 구간을 나눠 추출하면 안전합니다.

## 동작 방식

1. `샘플 간격`(기본 0.5초)마다 영상을 해당 시점으로 이동해 악보 영역만 캔버스로 잘라 읽음
2. 연속 샘플의 **변화 점수**(변한 픽셀이 몰려 있는 세로 열의 비율)로 "같은 악보가 정지한 구간"을 찾음
   - 악보 교체/페이드: 점수 큼 (0.3 이상) · 얇은 재생 커서/압축 노이즈: 점수 작음 (0.02 이하)
   - 느린 페이드는 구간 첫 샘플과의 점수(`느린 페이드 기준`)로 차단
3. 구간 안 프레임을 **픽셀별 중앙값**으로 합쳐 대표 이미지를 만듦 → 움직이는 커서 제거
4. 직전 악보와 같으면 병합. 2초 이하로 짧게 정지했고 앞뒤 페이지의 혼합(크로스페이드 중간)으로 설명되는 후보는 제외 표시(GUI에서는 체크 해제 상태). 악보가 성긴 페이지는 영향받지 않음
5. 같은 악보가 곡 중간에 다시 나오면 그대로 다시 포함

## 마디 정리 (겹침 제거)

커서를 따라 화면이 가로로 넘어가는 영상은 연속한 조각이 서로 겹쳐서, 조각마다 마지막 마디가 잘리고 다음 조각 왼쪽에 같은 마디가 중복됩니다.
추출이 끝나면 스크롤형 영상으로 확실할 때 **자동으로** 적용되고(결과 화면 위쪽 **마디 정리** 버튼으로 다시 실행하거나 "원본 조각 보기"로 되돌릴 수 있음), 하는 일은 다음과 같습니다:

1. 연속한 조각 사이의 가로 이동량(겹침 위치)을 찾고 (열별 잉크 분포로 후보를 뽑은 뒤, 겹친 영역의 픽셀이 실제로 같은지로 확인)
2. 겹치는 조각들을 하나의 긴 띠로 이어 붙이고
3. 띠에서 마디선을 찾아 마디선에서만 줄을 나눕니다 → 모든 줄이 온전한 마디로 시작하고 끝납니다. 줄은 항상 왼쪽 정렬하고, 악보선 위쪽(마디 번호·코드명)은 마디선에 걸쳐 있는 경우가 많아, 마디선이 아니라 그 근처의 빈 틈에서 자릅니다. 마디선에 걸친 번호·코드명은 반쪽으로 잘리지 않고 통째로 그 마디가 시작하는 줄에만 나옵니다.

- 반복되는 마디 때문에 후보가 여러 개로 같게 보일 수 있어, 확실한 쌍들의 이동량이 일정하면(페이지를 넘기는 거리는 보통 일정) 그 값을 기준으로 삼습니다.
- **자동 적용 조건**: 확실한 쌍들의 이동량이 일정하고(스크롤형), 이어진 쌍이 2개 이상이며 전체의 60% 이상일 때만 자동으로 적용합니다. 페이드/컷으로 페이지가 통째로 바뀌는 영상에서는 아무것도 바뀌지 않고 메시지도 없습니다. (버튼을 직접 누르면 조건 없이 시도하고, 겹침이 없으면 알려 줍니다)
- 확신이 없는 쌍은 **이어 붙이지 않습니다** (마디가 사라지는 것보다 중복이 남는 편이 낫습니다). 겹침이 없는 영상(페이드/컷으로 페이지가 통째로 바뀌는 유형)에서는 "겹치는 조각을 찾지 못해 그대로 둡니다"라고 알리고 아무것도 바꾸지 않습니다.
- 결과가 이상하면 **원본 조각 보기**로 되돌릴 수 있습니다. 선택 해제한 조각은 정리에서 빠집니다.
- 한계: 가로 스크롤 전제 (세로로 넘어가는 영상은 대상 아님), 마디선이 보이는 악보 전제, 움직이지 않고 오래 떠 있던 노란 커서는 중앙값으로 지워지지 않아 이어 붙인 결과에 남을 수 있음.

## 튜닝 가이드

| 증상 | 조치 |
|---|---|
| 같은 악보가 여러 조각으로 쪼개짐 | `같은 악보로 볼 기준`, `느린 페이드 기준`을 올림 |
| 서로 다른 악보가 하나로 합쳐짐 | `같은 악보로 볼 기준`, `중복 병합 기준`을 내림 |
| 짧게(1초 미만) 보이는 악보가 빠짐 | 샘플 간격을 0.25로 |
| 페이드 잔상이 섞임 | `페이드 잔상 판정`을 올림 (예: 0.9) |
| 페이지가 잔상으로 오판되어 제외됨 | 결과에서 해당 조각을 체크하거나, 판정을 0으로 |
| 배경 영상이 악보 뒤로 비침 | 영역을 악보 안쪽으로 좁게 |

## 알려진 한계

- H.264/VP9 외 코덱(HEVC 등)은 브라우저가 재생하지 못해 열 수 없음 → H.264 mp4로 변환
- 영상 길이와 비슷한 시간이 걸림 (3분 40초 영상 약 2분, PC에 따라 다름)
- 화면이 겹치게 스크롤되는 영상에서는 조각 사이에 같은 마디가 중복됨 (중복 정리는 다음 단계)
- 유튜브 URL 미지원

## 구조

```
docs/index.html   # 화면 (파일 하나 + 아래 스크립트)
docs/app.js       # 화면 동작: 영상 열기, 영역 지정, 프레임 읽기, 결과/다운로드
docs/core.js      # 알고리즘 (DOM 무관, Node에서도 동작): 변화 점수, 구간 추적, 중앙값 합성, 페이드 판정
docs/stitch.js    # 마디 정리: 겹침 찾기, 띠 만들기, 마디선 검출, 줄 나누기 (DOM 무관)
docs/pdf.js       # A4 배치 + 외부 라이브러리 없는 PDF 작성기
docs/media.js     # videos/ 목록, 내 컴퓨터 폴더 선택
tests/browser/    # 테스트 (아래)
tests/tools/      # 테스트 영상 생성기 (파이썬, 개발용)
```

## 테스트

```bash
node tests/browser/unit.mjs                       # 알고리즘 단위 테스트 (브라우저 불필요)
node tests/browser/stitch.unit.mjs                # 마디 정리 단위 테스트 (합성 악보, 브라우저 불필요)
python tests/browser/tidy_e2e.py cases.json OUT   # 마디 정리를 실제 영상으로 (cases: name, video, bbox, rows)
node tests/browser/pdf.test.mjs OUT.pdf a.jpg ... # PDF 작성기·배치
python tests/browser/ui.py VIDEO [shot.png]       # 화면 동작 (Playwright + Chrome)
python tests/browser/mobile.py VIDEO [SHOT_DIR]   # 휴대폰 화면 (Pixel 7 에뮬레이션, 터치·공유 시트)
python tests/browser/pwa.py VIDEO                 # 설치 정보 + 서버를 끈 뒤(오프라인) 열기·추출
python tests/browser/folder.py SITE_ROOT          # videos/·폴더 선택 (docs/ 와 videos/ 가 있는 폴더)
python tests/browser/e2e.py cases.json OUTDIR     # 실제 Chrome에서 tests/browser/expected/*.json 과 비교
```

`cases.json`: `[{"name": "cut", "video": "경로.mp4", "bbox": [0,640,1920,380], "expect": 4}, ...]` (name은 `expected/` 파일명).
합성 영상은 `python tests/tools/synthetic.py out.mp4`, `python tests/tools/sparse.py out.mp4`로 만듭니다 (opencv-python-headless, numpy, Pillow, ffmpeg 필요).
